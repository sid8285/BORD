# Technology assumptions

Registered at Checkpoint 1. From Checkpoint 2 on, every status cites an evaluation run in `results/`. Statuses use the course's words, as the harness writes them in `summary.json`: **Holding** means the point estimate clears the threshold; **Weakened** means the point estimate misses but the 95% Wilson interval still includes the threshold; **Broken** means the point estimate and the whole interval miss. Both CP2 summaries were recomputed in these words (`bord.resummarize`).

| # | Assumption | Basis | Status | Evidence |
|---|---|---|---|---|
| 1 | A frontier multimodal LLM judges honest single-scene pairs with at least 90% accuracy, but used alone it accepts at least 30% of adversarial submissions. | CP2: measured with Qwen3-VL 8B Instruct, an open-weight model, in place of a frontier LLM. CP3: measured with Claude Opus 5.5, a frontier model, through the Anthropic API, on 26 honest pairs and 79 adversarial attempts. The harness reports both halves separately, with 95% Wilson intervals. | Broken (CP3; Weakened at CP2) | `results/20261026T022525Z_claude-opus-5-5_anticheat/summary.json` → `assumptions.1`. Honest: 26/26 = 100% [87%, 100%], holding (not significant). Fooled by the model alone: 7/78 = 9% [4%, 17%] (one timeout has no verdict), so the whole interval is below 30%: the frontier model is fooled less often than assumed. By category: resubmitted 3/3, ai_edited 3/5, reused 1/16, wrong_scene 0/25, web_sourced 0/26, recaptured 0/3. CP2 (Qwen3-VL 8B): `results/20261012T012236Z_qwen3-vl-8b-instruct/summary.json`, fooled 7/31 = 23% [11%, 40%]. |
| 2 | One two-image verification call costs under $0.02 and returns in under 8 s at p95. | CP3: Claude Opus 5.5 through the Anthropic API, priced from the [official pricing page](https://platform.claude.com/docs/en/about-claude/pricing) ($4 input, $20 output per million tokens). ## Platforms
- Backend: [FastAPI](https://fastapi.tiangolo.com/)
- Frontend: [React](https://react.dev/)
- Payments: [Stripe test mode](https://docs.stripe.com/testing)
- Verdict model (chosen in Checkpoint 2): [Qwen3-VL](https://ollama.com/library/qwen3-vl) 8B Instruct, open weights, run locally with [Ollama](https://ollama.com) through its OpenAI-compatible API. The same code can target [Alibaba Cloud Model Studio](https://help.aliyun.com/en/model-studio/qwen-vl-compatible-with-openai) or a vLLM server. The [Anthropic Claude API](https://platform.claude.com/docs/en/about-claude/pricing) (Claude Opus 5.5) is the frontier model used for the CP3 evaluation.
- Image libraries: [imagehash](https://github.com/JohannesBuchner/imagehash), [OpenCV](https://opencv.org/)
